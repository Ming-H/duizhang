## 3. 评分口径（judge 规则）

- **retrieval**：期望文档在 top-3 命中或出现在引用（多期题用 `expect_docs`
  全部在场——只中一期不算过）
- **answer**：真值数字（或亿级换算）出现在答案
- **refusal**：陷阱题 `verdict=refused` 且答案无编造数字
- **通过线**：llm 模式 ≥ 0.85 视为达标（0.8b 大脑的合理线）

### 三轮：结构化数据行 + 投资分析层的结论（用户实测「很乱」驱动）

**数据层（已解决）**：骨架从原始表格行（本期/同期/同比混排一串数字）
升级为结构化行 `期间（口径）：营收 X 亿（同比 Y）；归母净利 Z 亿
（同比 W）[引用]`——确定性解析（≥1e6 大数门槛防残缺数字、断词行
注入、口径标注），2026H1 的会计准则段落噪声被行模式匹配排除。
评估期望词同步对齐亿级真值（与真值表「约合」列一致，非放水）。

**分析层（模型能力边界，如实定档）**：数字闸门（分析数字必须全部
来自数据行）三组实测全过，但 0.8b 语义级不可靠——+90.05% 说成
「大幅回落」、+69.40% 说成「暴跌」、累计/单季混淆、编造产能归因。
数字对 ≠ 结论对，语义闸门无法机械化。**分析层默认关闭**
（`TALLY_TREND_ANALYSIS=enabled` 开启，建议配 glm-5.3 级模型）；
骨架的同比数据本身即客观分析。

### 两轮测试累计逼出的修复（全部已入库，各带回归测试）

| 发现 | 修复 |
|---|---|
| LLM 拒答变体话术（「**未**找到依据」）绕过检测 | no_evidence 变体清单 + <15 字符兜底 |
| 「净利润」默认口径不明（答成扣非） | 提示词明确默认归母口径 |
| `revenue`/`profit` 英文词查不中中文语料 | METRIC_SYNONYMS 补英文项 |
| Agent 写入裸检索词（营收）致抽取式零重叠拒答 | effective_query 记录**扩展后**检索词 |
| heuristic 趋势题退化为普通抽取式 | trend 骨架提出 llm 条件（模式无关） |
| 真值行被无数字表头块挤出前排（词面匹配更强） | metric 意图主要会计数据**整页前置** |
| PDF 断词工件：标签行被空表头过滤丢弃，数字行以「润（元）」开头 | 抽取式断词注入（润（元）→净利润） |
| 数字问句下无数字表头行压过真值行 | 无数字句 ×0.3 强降权 |
| 0.8b 把「股价会涨吗」判 metric 拿财报答行情 | 股价/涨跌类守卫 → other |
| 0.8b 同一 query 三次返回三种意图（metric/trend/summary） | trend 降级目标改为规则意图；公司漏检守卫（规则子串匹配确定性补全） |

## 4.5 判定语义（v0.7 数字为真批收口）

- **数字关键词只守左边界**（`(?<!\d)` 前邻不得是数字）：堵「3.6」子串命中
  「13.68」、「36,000」命中「136,000」的假命中；**右侧放行是本集约定**——
  关键词普遍前缀截断（51.7 对 51.71、38,239 对 38,239,935,640），右边界
  一禁即误杀（innolight 实测 0.963，CI 门槛当场抓回）。
- **forbid_keywords（可选字段）**：答案出现明确不该出现的值 → 该题判
  miss——单测层负向断言能力上移到 eval 层。示范：扣非题 forbid 归母
  同期数 1,582,876,128（问 X 不得答成姊妹口径 Y）。
- **CI 门槛**：`eval --min-retrieval/--min-hit/--min-refusal` 低于阈值
  非零退出——修前 eval 恒 exit 0，CI 只防崩溃不防退化。
